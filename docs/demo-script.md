# 答辩展示流程

1. 打开首页，介绍倒计时、热门球队、赛程、可信新闻和七Agent能力。
2. 进入AI分析中心，依次提问“法国夺冠概率”“姆巴佩状态”“为什么西班牙克制法国”，展示自动路由到不同Agent。
3. 进入球迷空间，选择法国、日本、姆巴佩和竞争球队巴西，保存后刷新世界杯日报。
4. 打开世界杯中心，展示赛程、积分榜、ECharts图表和D3淘汰赛晋级图。
5. 打开球队与球员详情，展示阵容、战术、能力雷达和AI分析入口。
6. 在新闻中心点击联网刷新，再粘贴一条夸张标题，展示可信度评分与多源核验逻辑。
7. 在视觉分析上传球衣、国旗或比赛截图，展示标注图、阵型和战术风险。
8. 在AIGC创作中输入“法国夺冠”，展示实际生成的PNG海报、朋友圈文案、宣传图Prompt和视频脚本。
9. 最后打开 `/docs` 展示完整API，并说明SQLite/PostgreSQL兼容、ARK模型增强和LangSmith追踪。
